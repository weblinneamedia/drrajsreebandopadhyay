# Dr. Rajarshi Bandyopadhyay — Personal Medical Website

Next.js website for Dr. Rajarshi Bandyopadhyay, Oral Oncologist & Maxillofacial Surgeon in Kolkata.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project Structure

- `src/app` — Pages and API routes
- `src/components` — UI and layout components
- `src/data` — Doctor details, treatments, blog, FAQs
- `public/images` — Logo and doctor photos

## Configuration

Copy `.env.example` to `.env.local` and set:

- `NEXT_PUBLIC_GA_ID` — Google Analytics ID (optional)
- `APPOINTMENT_NOTIFICATION_EMAIL` — Appointment form notification email

Edit doctor details in `src/data/doctor.ts`.
